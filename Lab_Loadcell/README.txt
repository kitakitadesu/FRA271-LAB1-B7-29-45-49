Matlab
1.FFT_LoadCell เก็บข้อมูลจาก Loadcell 10 วินาที time step 0.001 มาเก็บบน Simulink และทำ FFT 
2.MOVING นำข้อมูลชุดเดียวกับ FFT มาทำเป็น Moving average และทำออกมาเป็นกราฟ 
3.Calibrate ใช้สำหรับการเก็บข้อมูล โดยเก็บข้อมูลน้ำหนักที่เราชั่งจริงและเก็บข้อมูล 8 วินาทีขณะนำมาเฉลี่ย โดยตัดข้อมูล 3 วินาทีแรกทิ้งเพื่อให้ได้ข้อมูลวในช่วงที่สัญญาณนิ่ง
	ขั้นตอนการทำงาน	
	1.รันโค้ด เริ่มทำการเก็บค่าที่ 0 กรัม
	2.กรอกน้ำหนักของถุงทรายกด Enter
	3.โปรแกรมเก็บ Voltage 5 วินาทีมาเฉลี่ยและเก็บเฉลี่ย 3 ครั้ง 
	4.รันโค้ดเก็บค่าตั้งแต่ 0-7.5 กก.
4.Plot_Calibration นำข้อมูลที่เก็บได้มาทำ Linear regression และแสดงผลออกมาเป็นกราฟ
5.Error_Plot นำสมการที่ได้จากการทำ Linear regression มาคำนวณเป็น้ำหนักและนำมาคำนวน Percent error 
6.Realtime ใช้สำหรับการนำข้อมูลการชั่ง เมื่อไม่มีน้ำหนัก ขณะวางน้ำหนักและวางน้ำหนัก เพื่อดูการตอลสนองของ Loadcell
